# Fundamentals of Programming
This repository contains a collection of Java programs developed during my Fundamentals of Programming course.

# What will you learn from this repository?

This repository provides hands-on examples to help you grasp fundamental programming concepts in Java. By exploring these programs, you'll gain practical experience in user input handling, variable usage, loop structures, basic calculations, and more, contributing to a solid foundation in Java programming.

# This repository contains the following Java Programs
**GreetingProgram**
- This Java program prompts the user for their name and age, then prints a personalized greeting.

**RectangleAreaCalculator**
- A program demonstrating double-type input, simple calculation, and result output.

**BMICalculator**
- Calculates and displays the Body Mass Index (BMI) based on user's weight and height.

**BasicCalculator**
- A simple calculator performing addition, subtraction, multiplication, and division.

**CheckPositiveOrNegative**
- Determines whether a given number is positive or negative.

**doWhileLoop**
- Uses a do-while loop to print numbers from 10 to 1.

**doWhileLoopPyramidPattern**
- Prints a pyramid pattern using nested do-while loops.

**MetricConversion**
- A metric conversion tool for kilograms to pounds, pounds to kilograms, ounces to grams, and grams to ounces.

**NestedForLoop**
- Uses nested for loops to print a right-angled triangle pattern of numbers.

**AirFareActivity**
- A simple airfare calculator considering fare amount, customer code, discounts, and additional charges for business class travel.
